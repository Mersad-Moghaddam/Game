# Malvandi vs. Bugs Implementation Plan

**Goal:** Build and run the approved 60-second programmer arcade game.
**Architecture:** Pure simulation module, Canvas renderer and DOM input layer.
**Tech Stack:** HTML, CSS, JavaScript modules, Node tests, Python HTTP server.
**Spec:** docs/superpowers/specs/2026-09-14-malvandi-design.md

## Global Constraints
- Single-screen 2D action; Malvandi is the protagonist and bug creator.
- No runtime dependencies or external assets.
- Three hearts, 60 seconds, deployment waves every 15 seconds.

## Task 1: Simulation
- [ ] Write tests in game.test.mjs against createGame() and update(game, input, dt).
- [ ] Run `node --test game.test.mjs` and confirm missing simulation failure.
- [ ] Implement game.mjs: bounded normalized movement, nearest-target patches,
  pursuing enemies, collision immunity, coffee boosts, waves, win/loss states.
- [ ] Run `node --test game.test.mjs` and confirm passing behavior.

## Task 2: Playable interface
- [ ] Create index.html with HUD, canvas, start/result dialog and touch controls.
- [ ] Create style.css using the spec palette and responsive window layout.
- [ ] Create main.mjs to draw the arena and characters and connect input to simulation.
- [ ] Add keyboard, pointer controls, pause on blur, and guarded best-score storage.

## Task 3: Verify and run
- [ ] Serve using `python3 -m http.server 5173 --bind 0.0.0.0`.
- [ ] Run Node tests and browser smoke checks of start, movement, shooting and pause.
- [ ] Confirm HTTP response, review browser screenshot, and provide local URL.
